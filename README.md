# jogoMario

## Descrição do Jogo Mario
O jogo apresenta um cenário simples no qual o personagem percorre o caminho continuamente e deve saltar para desviar dos obstáculos que aparecem ao longo do percurso. A interação ocorre por meio de eventos de **teclado**, permitindo a movimentação do personagem e a contagem de pontos por obstáculo ultrapassado. Caso o Mário colida com algum obstáculo, o jogador perde a partida.

## Objetivo
O presente projeto tem como objetivo o desenvolvimento de um jogo com a temática do Mário, utilizando as tecnologias **HTML, CSS e JavaScript**. Busca-se, por meio do desenvolvimento, compreender, na prática, a utilização dessas tecnologias, a criação e aplicação de eventos de clique, a implementação de imagens, a contagem de pontos e a lógica necessária para o funcionamento do jogo. Além disso, o projeto proporciona à equipe a utilização do **Git e GitHub** para a prática de versionamento, organização e colaboração durante o desenvolvimento.

## Tecnologias utilizadas

## Instruções para instalação
1. Faça a clonagem do repositório: ``git clone URL_DO_REPOSITORIO``
2. Abra o arqivo no VsCode
3. Instale as últimas atualizações: ``git pull origin dev``

## Instruções para execução
1. Abra o projeto no VsCode
2. Caso não tenha, instale a extensão ``Live Server``
3. Acesse a pasta **frontend**
5. Acesse o arquivo **index.html**
6. Clique no botão do **Live Server**
